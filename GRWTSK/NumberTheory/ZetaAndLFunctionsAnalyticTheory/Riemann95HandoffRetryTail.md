Failure of fairness supplies a live time with no future stage increase or terminal state. Stage monotonicity rules out a local exit anywhere on that tail, so each tick is a retry. Conversely induction over a retry tail fixes the full reference configuration, ordinal address, source step count, revision and certificate list, and preserves liveness. The constant retry construction and a retry run whose rational heat observation at slot zero is exactly the current tick are checked controls. The second control falsifies the implication from strictly increasing observations to arithmetic progress at this controller interface. It makes no assumption about realizability by a physical heat process.

To recover fairness on an implementation, one must rule out a permanent live retry tail, for instance by validating eventual eligibility and commitment for the current full root and revision. This is a separate physical or scheduling premise. The exact arithmetic halt test remains the existing controller's certified terminal branch.
