# `GRWTSK.IntegerFactorization.Division.division_on_stacks`

Local attribution: grwtsk contributors.

[Local declaration](../RudichRousseauDivisionOnStacks.lean). The fixed bit-stack program transfers the input from stack 0 to stack 1, simulates the compiled division program and transfers the result back. These moves reverse orientation twice. The same simulator preserves every other stack, and its finite alphabet and finite control implement each step in the Mathlib TM2 model. The clean final stack frame has one returned word whose memory interpretation gives the input, quotient, remainder, and cleared division workspace. Compiler address registers in that word may retain values. The cutoff bounds on both finite memory length and cell values explicitly charge the simulator’s data-dependent tape movement. The caller must supply the declared heap input encoding.

The upstream source is Isaac Rudich and Louis-Martin Rousseau, *Deterministic Factoring in Time N^o(1)*, Hexagon 2610.00600v1, repository revision `c91cc3f4947caca8977e81a5d14244f73b5ae2b1`. The authors designed and audited the challenge statement and credit Claude (Anthropic) with the proof ideas and Lean code. The provider code is Apache-2.0.
