# `GRWTSK.IntegerFactorization.Division.divide_run`

Local attribution: grwtsk contributors.

[Local declaration](../RudichRousseauExactDivision.lean). The fixed program performs restoring binary division on banks of width w, with a w+1-bit remainder. At each of w steps the prefix of the dividend equals d times the current quotient plus the current remainder, which lies below d. On reading a bit, the provider compares the shifted remainder with d, conditionally subtracts d and stores the comparison bit. The provider leaves its copy of the divisor in array 4. The local cleanup widens the length by one, clears every cell of that copy and restores the width temporary. Both inputs must fit w bits and d must be positive. The resulting whole source state and quadratic bound are available to the register compilation.

The upstream source is Isaac Rudich and Louis-Martin Rousseau, *Deterministic Factoring in Time N^o(1)*, Hexagon 2610.00600v1, repository revision `c91cc3f4947caca8977e81a5d14244f73b5ae2b1`. The authors designed and audited the challenge statement and credit Claude (Anthropic) with the proof ideas and Lean code. The provider code is Apache-2.0.
