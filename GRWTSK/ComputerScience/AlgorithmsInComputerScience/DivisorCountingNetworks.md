## Incidence, assignment and precision

Each ordered input port is an edge and a choice of endpoint. The validity condition assigns each endpoint to exactly one vertex and excludes repeated occurrences there. The explicit bipartite construction replaces each old edge with two half edges. It reconnects the old ports to the first endpoint of each half edge in the original order. Both other endpoints meet at one new binary equality vertex. The operation preserves incidence validity even on parallel edges, and has exactly twice as many edges. Old degrees are unchanged and every added vertex has degree two. [Construction and theorems](DivisorCountingNetworks.lean)

Every accepting assignment uniquely extends by giving its two halves the original bit. Conversely, selecting the false endpoint at every old edge recovers the assignment, since equality forces the other half. The two maps are inverse on satisfying assignments. An injection into the full Boolean cube gives an upper bound of two to the power of the original edge count. Taking a modulus of twice that bound suffices to reconstruct the ordinary integer, including the all-true network that reaches the upper bound. Choosing only the bound itself as modulus would return zero in that example. For the factorization application, the degree constant can be absorbed in the free size parameter of D.1 while keeping that parameter linear in the bit width. The Lean statements charge wire cardinality and degree. Encoding lengths, evaluator construction and time and space to produce these descriptions are separate costs.

## Fixed interface and linear size

A public product fixes the full $2b$-bit output, including its high zeroes. A prefix fixes the first $b-r$ bits of the first factor, using the positions corresponding to the most significant bits. Given the mapping from these positions to edge identifiers, `OrderedPorts.pin` enforces an optional value on each original wire inside the adjacent predicates. The local predicate first checks the original gate and then tests each prescribed bit in port order. On a well-formed graph each pin is seen at an endpoint, including on a loop. The proof `pin_accepts_iff` identifies the exact subset of accepted assignments. Pinning changes neither the port lists nor their lengths. The theorem `readout_of_interface` combines the pin transformation, graph subdivision, integer residue and unit correction with a single bijection for the unpinned multiplication supplier. Its interface premise states exactly which pinned bit pattern selects the public product and prefix in the original words. The supplier still has to identify its actual input and output ports and prove these semantics. [Interface pinning](DivisorCountingNetworkPins.lean)

With $b$-bit factors, Theorem 3 of Akshima et al. gives fewer than $1100(b+1)$ Boolean edges, and old degrees below $136(b+1)^{3/4}$. Choose $s=136^2(b+1)$. After subdivision the edge count is below $2200(b+1)\le s$. For old vertices, $136\le(136^2)^{9/10}$ and $(b+1)^{3/4}\le (b+1)^{9/10}$ imply the required degree bound $s^{9/10}$. The degree of each new equality vertex is two, which also fits. The parameter is linear for every input length. Explicit binary edge indices may already take logarithmically many bits apiece. The local predicates need polynomial-time evaluators and the family needs an effective constructor. Expanding a gate of arity $d$ into a $2^d$-entry table or compiling a general polynomial computation to a polynomial number of CNF wires does not establish a linear bound in the original input width. [Size proof](DivisorCountingNetworkSize.lean)

The target theorem also bounds the total number of vertices by a polynomial in $s$. Subdivision produces $|V|+|E|$ vertices. Isolated vertices are real scalar predicates, so an edge bound alone cannot control their number. The modulus uses $P_0=|E|+1$ after subdivision because equalities preserve the original assignment count. For these zero-one weights one may take truncation order $\ell=1$. The coefficient ring is then $(\mathbb Z/2^{P_0})[V]/(V)$, whose constant-term map identifies it with $\mathbb Z/2^{P_0}$. For arbitrary finite vertex and wire types, `scalar_eq_assignments` proves that the sum of products of Boolean gate entries in any commutative semiring equals the natural count cast into that ring. A rejected assignment has a zero factor, and an accepted assignment contributes one. The theorem `scalar_prefixCount` applies a unital coefficient map, reads the natural residue and performs the unit correction on the actual pinned, subdivided graph. The sharp contraction runtime requires separately proving the stated uniform graph-description, entry-evaluation and workspace bounds. ## Divisor readout

Fix a positive $n<2^b$, the full product word, and a prefix of the first multiplicand. Take the two $b$-bit multiplicands as naturals below $2^b$. Projection of a valid pair onto its first factor has inverse $d\mapsto(d,n/d)$. Both words fit because both factors are at most $n$. The inverse proof uses positivity of the first factor, which would fail at a zero product. A parsimonious multiplication supplier gives a bijection between its accepting assignments and these fixed-interface pairs. Composing the bijections and subtracting the single assignment for $d=1$ precisely when its padded bits have the chosen prefix yields the cardinality consumed by the search. The input $n$ itself stays in the count, so the search returns $n$ on a prime. If a network gives two representations for the same intermediate residue, the multiplicity changes and that supplier fails the required bijection. The argument uses no assumption concerning SAT, class groups or prime distribution. The theorem about multiplication readout explicitly takes the multiplication-network bijection as input. A closed bounded-width CNF theorem or an expression for a field-valued signed contraction supplies neither this bijection nor the generic D.1 runtime.
