# Corrected off-line volume-packing endpoint

The auxiliary normalized coefficients A_n and T_n were totalized by assigning zero on their singular loci. Therefore, at a=0, the current normalized axial coefficient is identically zero. An all-zero claim demanding a positive scaled limit for every zero is too strong and is not the right terminal interface.

The RH contradiction needs scale data only under the hypothetical assumption that a zero is off the critical line.

The corrected supplier is

for every actual nontrivial zero z:
  if a=Re(z)-1/2 is nonzero,
  provide QuarticVolumePackingScaleDataAtZero(z).

The existing volume-packing endpoint then forces Re(z)=1/2, contradicting the premise a!=0.

This is logically sufficient for RH and does not request impossible positive-limit data on a zero already on the critical line.

The old certificate type remains useful as the local contradiction packet. The corrected global quantifier is OffLineQuarticVolumePackingScaleClaim.
