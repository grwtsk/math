# Structured four-distinct Chowla premise-strength correction

Issue: #905  
Parent: draft PR #903 at `5a938e36344f046472876a0df572774ff433f7f6`.

The parent introduced
```lean
FourDistinctChowlaFiniteSupportEnvelope
```
over arbitrary finite sets of unrelated four-distinct Chowla data. That premise is broader than the centered-winding dependency path consumes.

The actual route only uses configurations generated by:
- endpoint `b`;
- effective square modulus `d`;
- positive winding `1 <= z <= floor(b/d^2)`;
- lag `ell=z*d^2`;
- endpoint parity `r=0,1`;
- the existing even/odd positive endpoint shift families;
- endpoint-valid centers;
- nondegenerate admissible shift pairs.

The new source packages exactly that quantity:
```lean
regularCenteredStructuredFourDistinctEndpoint
RegularCenteredStructuredFourDistinctEnvelope.
```

Absolute values are retained at the exact four-family/modulus level used by the centered-winding branch.

No equivalence with general order-4 Chowla is claimed, and no equivalence with RH is claimed.

The analytic frontier should therefore use
```text
STRUCTURED_CENTERED_FOUR_DISTINCT_ESTIMATE_OPEN
```
rather than an arbitrary finite-support order-4 Chowla premise.
