# Optional prismatic capabilities for fabrics

This declaration-free umbrella exposes abstract, explicitly parameterized
prismatic capabilities.  An arithmetic realization is extra,
representation-dependent data.  This project does not claim complete
formalisations of prisms, derived p-completion, or prismatic cohomology.

A simplicial source map induces the deliberately contravariant prismatic
comparison.  Frobenius is not a runtime epoch or event counter, and Nygaard
filtration levels are not runtime priorities.  “THH strain tensor” remains an
informal phrase unless an actual tensor-valued invariant is supplied; a
relative-THH interface is not itself a construction of THH.  Determinant
transport is available only from certified chain-level quasi-isomorphism data,
never from an arbitrary fabric reaction.
-/
