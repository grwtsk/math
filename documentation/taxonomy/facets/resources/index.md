# Resource kinds

[Facets](../index.md) · [Registry](../../registry.md)

These proposed resource kinds index maintained formalization resources without
pretending that every module establishes mathematics in its filename's subject.
They are not subject-specialization nodes, proof statuses or exclusions from
maintenance.
