                                                                                     Abstract
                                                       The ABC conjecture of Masser and Oesterlé states that if (a, b, c) are
                                                   coprime integers with a + b + c = 0, then sup(|a|, |b|, |c|) < cǫ (rad(abc))1+ǫ
                                                   for any ǫ > 0. In [2], Oesterlé observes that if the ABC conjecture holds
                                                   for all (a, b, c) with 16|abc, then the full ABC conjecture holds. We extend
                                                   that result to show that, for every integer N , the “congruence ABC con-
                                                   jecture” that ABC holds for all (a, b, c) with N |abc implies the full ABC
                                                   conjecture.


                                             1     Introduction
                                             The ABC conjecture was introduced by Masser and Oesterlé in 1985, and has
                                             since been shown to be related to many other conjectures, especially conjectures
                                             regarding the arithmetic of elliptic curves [1].
                                                 For our purposes, an ABC-solution s is a triple (a, b, c) of distinct relatively
                                             prime integers satisfying a + b + c = 0, and such that a and b are negative.
                                             (The requirement that the integers be distinct is included only to simplify the
                                             exposition below.) If n > 0 is an integer, the radical rad(n) is defined to be the
                                             product of all primes dividing n.
                                                 For any ǫ > 0, we define a function on ABC-solutions by

                                                                    f (s, ǫ) = log(c) − (1 + ǫ) log rad(abc).

                                                 Then the ABC conjecture can be phrased as follows:
                                             Conjecture 1 (ABC conjecture). For each ǫ > 0, there exists a constant Cǫ
                                             such that

                                                                                   f (s, ǫ) < Cǫ

                                             for all s.
                                                 In [2], Oesterlé showed that the ABC conjecture is equivalent to a conjecture
                                             of Szpiro on elliptic curves ([2, Conj. 4]) In the proof, he observes that if the

   It has long been known to experts that the congruence ABC conjecture for
any N is equivalent to the full ABC conjecture. However, a proof has never
to our knowledge appeared in the literature, and we take the opportunity to
provide one in this note.

ABC conjecture for N is true. Then there exists Cǫ such that

for all s with N |abc.
    Let n = φ(N ). If N = 2, Theorem 3 is trivial. We may therefore assume
that n is even.
Lemma 5. Let (A, B, C) = Θn (s). Then N |ABC.
Proof. Suppose p is an odd prime dividing N , and let pν be the largest power
of p dividing N . Then (p − 1)pν−1 |n. In particular, ν < n. If p divides c or
a − b, then pν |pn |ABC. If p divides neither c nor a − b, then −A = 2−m (a − b)n
and C = 2−m cn are congruent mod pν ; therefore, pν |B.
    Now let 2ν be the largest power of 2 dividing N . If c is even, then so is a − b,
and exactly one of c and a − b is a multiple of 4. Thus, one of (a − b)n and cn
is a multiple of 4n . Since, in this case, A = 2−n (a − b)n and C = 2−n cn , one
of A and C is a multiple of 2n , whence also of 2ν . If, on the other hand, c is
odd, then so is a − b. Then (a − b)n and cn are both congruent to 1 mod 2n u,
so 2ν |B.
