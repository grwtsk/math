From the repository root with requirements-tests.txt installed:

  python3 -B scripts/verify_density_hankel.py --mode both

The unchanged runner regenerates the source and density certificates. It does
not read the four generated records, so no decompression is needed to replay.
It still checks its fixed 23-input manifest. For example, view a stored report:

  xz -dc evidence/number-theory/zeta/density-hankel-20261015/source-32-384.json.xz

publication-replay.json retains the new complete replay. Six repeated producer

stderr, exit codes, arguments and proof-status fields remain inline. Each linked
producer output was freshly reproduced and matched byte for byte. The original
full replay is retained separately as fresh-replay.json.xz.
