# Spectral-volume profiles

Maintained by grwtsk contributors.

The active profile is [spectral-volume-radius3-v2](../ranking-profile.json).
Each observation records the exact profile digest used for its calculation.
Changing weights creates a new profile identity and requires a new calculation
from the same eligible graph before comparing the resulting scores.

Subject previews hash canonical sorted-key JSON. Historical complete-source
issuances retain the raw profile-file hash from their pinned source revision.
The archived v1 file preserves those original source706 bytes exactly.

| Profile | Edge weights | Radius | Upstream scope |
| --- | --- | ---: | --- |
| [v1](spectral-volume-radius3-v1.json) | Proof 1; statement 1 | 3 | Include |
| [v2](spectral-volume-radius3-v2.json) | Proof 1; statement 1; structural metadata 1 | 3 | Include |

Both profiles use tau one, distance decay one, no normalization, the standard
Lean axiom policy, and at most 128 vertices for exact evaluation. Every result
remains in the catalogue when its score is unavailable. Scores require complete
compiler-observed neighborhoods and matching source, environment, receipt, and
review bindings. Installed compiled toolchain inputs retain their recorded
verification boundary.

The [publication contract](../result-publication-contract.md) defines the metric,
eligibility gates, missing-data states, and composite root unions. Quantitative
metrics and qualitative rubrics have separate versioned observations.
