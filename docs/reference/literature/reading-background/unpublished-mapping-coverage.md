## How to read the statuses

- **Source-compared:** the specified passage was compared with code or recorded with a specific missing target. A correspondence may still be only an analogy or a conditional interface.
- **Previous map:** the original four comparisons remain unchanged.
- **Screened-unresolved:** a cited extracted passage was screened, with possible code-search locations and missing bridges. No source-specific mathematical match was established; this is deliberately excluded from `formalization_links`. The screening does not assert that no matching theorem exists elsewhere.

Every code lead below links to an immutable commit, exact declaration lines, Git blob and full-file SHA-256 in the JSON. Leads with no target say so. All proposed interpretations remain assistant-authored drafts, with null owner statements and understanding dates.
