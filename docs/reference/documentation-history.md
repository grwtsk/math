# Documentation provenance and evidence limits

Human mathematical direction: grwtsk contributors. Local derivation, formalization, checking and documentation assistance: OpenAI Codex. Each inherited source citation and individual upstream credit remains attached to its mathematical material. Local source is MIT; Lean and Mathlib retain their authorship and applicable Apache-2.0 notices. Custody is not authorship.

The previous flat pages mixed mathematical results with continuation instructions and execution history. Their mathematical sections now belong to subject/object pages. Verification procedures belong to reference; operational history is excluded from mathematical navigation. Exact original bytes remain in Git history and in a read-only, ignored local archive. The old README snapshot is also retained historically rather than offered as current guidance.

The [frozen section inventory](legacy-inventory.json) identifies the original revision, file hashes and character ranges. The [disposition ledger](documentation-layout.json) gives every block one primary destination or a historical disposition; explicit secondary destinations document mathematical splits. Those records establish byte identity and editorial coverage, not truth or acceptance. A section disposition does not mechanically prove that its meaning was preserved.

Inherited assertions about checked declarations are historical. A written argument is not a Lean theorem; a conditional result retains its assumptions; a cited external theorem is not a local proof. Contextual source bindings on written or literature pages identify related code without claiming that code proves the whole page. Source renaming and documentation reorganization do not refresh verification evidence.

Historical manifests and receipts retain their original paths, failures and limitations. Changed documentation-input paths invalidate the affected projection; unchanged Lean source does not require proof reconstruction solely for this editorial migration. Applicable fresh admission remains a separate obligation.

The full authoritative theorem catalog, proof graph, contribution review and theorem acceptance remain open beyond this structural documentation candidate. Missing historical attribution is recorded as unknown, never invented. Mathematical correctness, evidentiary admission and operational permission remain separate.
