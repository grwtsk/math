# Source attribution and rights

Preserve original mathematical authors, source editions, exact commit and
blob identities, declaration names, and the evidence scope of each claim.
[LICENSE](../../LICENSE), [NOTICE](../../NOTICE), and
[LICENSES/](../../LICENSES/) remain the source of legal notices.

[CITATION.cff](../../CITATION.cff) is a collection citation and does not
replace individual primary sources. Local content attribution is
`grwtsk contributors`; it does not replace genuine upstream authorship
or other contributors' Git identities. Neither a mathematical source
record nor a directory prime link grants permissions for an effect.
