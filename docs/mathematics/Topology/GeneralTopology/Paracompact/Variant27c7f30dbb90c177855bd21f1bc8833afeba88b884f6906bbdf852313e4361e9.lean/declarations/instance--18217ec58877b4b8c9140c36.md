        open covering of `s`. We choose a locally finite refinement `u' : s → Set X`, then
        `⋃ i, u' i` and `(closure (⋃ i, u' i))ᶜ` are disjoint open neighborhoods of `s` and `t`. -/

  refine { normal := fun s t hs ht hst ↦ this s t hs fun x hx ↦ ?_ }
