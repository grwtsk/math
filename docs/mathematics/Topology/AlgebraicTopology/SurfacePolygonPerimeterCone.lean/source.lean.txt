# A source-exact topological cone of the unpaired polygon perimeter

The parent #962 supplies a genuinely JOINTLY CONTINUOUS source-exact
radial map from the authentic polygon unpaired perimeter times the
unit interval into the previously constructed filled polygon quotient.

We make a new genuine point-set cone quotient, rather than merely
calling a product a disk. Its only gluing steps identify ALL points
at radial coordinate zero, and no two distinct points at nonzero
radius. The EqvGen relation is characterized exactly:
  coneConnected p q iff p=q or p.radius=q.radius=0.

The quotient carries the Mathlib coinduced topology, and the quotient
projection is continuous. The original joint map respects the
cone's exact apex relation because the previous source proved its
zero-radius slice is the same actual radial apex. Therefore it descends
to a continuous map Cone(P_k) -> FilledPolygonQuotient(k). Surjectivity
uses the original sector source representatives, not a rank argument.

This map is STRICTLY NONINJECTIVE at the outer boundary: the cone
retains two distinct source midpoints from opposite directed sides at
r=1, but the genuine paired boundary in the filled target identifies
them. The true cone is compact, and retains a continuous radial
coordinate.

This is an explicit mathematical cone and a continuous quotient-source
comparison. It is NOT a homeomorphism to the filled surface; nor is a
homeomorphism Cone(S¹) ≃ a standard closed disk constructed here.
The filled space's pushout/adjunction-space universal property, CW
cells, surface manifold, cellular/singular homology, van Kampen,
Hurewicz, hyperbolic lengths, Selberg, GUE, Chowla and RH remain open.
-/

/-- The SAME original finite directed side type is discrete; no
topology on the real tangential/radial unit intervals is changed. -/
local instance cornerDiscreteTopology (k : ℕ) :
    TopologicalSpace (PolygonCorner k) := ⊥

/-- Source of the topological cone: the actual unpaired cyclic perimeter
P_k (already a real quotient of 4g directed intervals), crossed with
the true compact radial unitInterval. -/
abbrev ConeCylinder (k : ℕ) : Type :=
  UnpairedPerimeter k × unitInterval

/-- THE ONLY primitive cone relation: collapse every pair of points
at radius zero, independent of their authentic unpaired perimeter
source identifiers. No relation identifies different positive-radii
points or entire boundary circles. -/
inductive PerimeterConeStep (k : ℕ) :
    ConeCylinder k → ConeCylinder k → Prop where
  | apex (x y : UnpairedPerimeter k) :
      PerimeterConeStep k (x, 0) (y, 0)

/-- The smallest equivalence relation generated by the actual apex
collapse, not an unconstrained all-points-equal relation. -/
def ConeConnected (k : ℕ) :
    ConeCylinder k → ConeCylinder k → Prop :=
  Relation.EqvGen (PerimeterConeStep k)

/-- Exact fiber description of the full generated cone equivalence.
At positive radii, it is just source equality. -/
theorem coneConnected_iff (k : ℕ) (p q : ConeCylinder k) :
    ConeConnected k p q ↔
      p = q ∨ (p.2 = 0 ∧ q.2 = 0) := by
  constructor
  · intro h
    induction h with
    | rel a b hab =>
        cases hab
        exact Or.inr ⟨rfl, rfl⟩
    | refl a =>
        exact Or.inl rfl
    | symm a b hab ih =>
        rcases ih with heq | ⟨ha, hb⟩
        · exact Or.inl heq.symm
        · exact Or.inr ⟨hb, ha⟩
    | trans a b c hab hbc ih1 ih2 =>
        rcases ih1 with heq | ⟨ha, hb⟩
        · subst b
          exact ih2
        · rcases ih2 with heq | ⟨hb', hc⟩
          · subst c
            exact Or.inr ⟨ha, hb⟩
          · exact Or.inr ⟨ha, hc⟩
  · rintro (heq | ⟨hp, hq⟩)
    · subst q
      exact Relation.EqvGen.refl _
    · rcases p with ⟨x, r⟩
      rcases q with ⟨y, s⟩
      dsimp at hp hq
      subst r
      subst s
      exact Relation.EqvGen.rel _ _ (PerimeterConeStep.apex x y)

/-- The actual Setoid of the radial cone, built from precisely the
relation whose fibers were computed above. -/
def coneSetoid (k : ℕ) : Setoid (ConeCylinder k) where
  r := ConeConnected k
  iseqv := Relation.EqvGen.is_equivalence _

local instance coneSourceSetoid (k : ℕ) : Setoid (ConeCylinder k) := coneSetoid k

/-- An ACTUAL topological cone carrier: the Mathlib quotient of
P_k × [0,1] by only its radius-zero apex equivalence. -/
def PerimeterCone (k : ℕ) : Type :=
  Quotient (coneSetoid k)

instance perimeterConeTopology (k : ℕ) : TopologicalSpace (PerimeterCone k) :=
  inferInstanceAs (TopologicalSpace (Quotient (coneSetoid k)))

/-- The cone's topology is exactly the Mathlib coinduced quotient
topology from its full genuine cylinder source. -/
theorem coneTopology_coinduced (k : ℕ) :
    (inferInstance : TopologicalSpace (PerimeterCone k)) =
      TopologicalSpace.coinduced
        (Quotient.mk' : ConeCylinder k → PerimeterCone k)
        (inferInstance : TopologicalSpace (ConeCylinder k)) := rfl

/-- The actual quotient map, not a relabelled identity map. -/
def coneProjection (k : ℕ) :
    ConeCylinder k → PerimeterCone k :=
  Quotient.mk (coneSetoid k)

theorem coneProjection_continuous (k : ℕ) :
    Continuous (coneProjection k) := by
  change Continuous
    (Quotient.mk' : ConeCylinder k → PerimeterCone k)
  exact continuous_quotient_mk'

theorem coneProjection_isQuotientMap (k : ℕ) :
    IsQuotientMap (coneProjection k) := by
  change IsQuotientMap
    (Quotient.mk' : ConeCylinder k → PerimeterCone k)
  exact isQuotientMap_quotient_mk'

/-- Equality of cone classes away from the apex is EXACTLY equality
of their original cylinder source points. Neither two distinct
perimeter points at r=1 nor two distinct interior points collapse. -/
theorem coneProjection_eq_iff_of_ne_zero (k : ℕ)
    (p q : ConeCylinder k) (hp : p.2 ≠ 0) :
    coneProjection k p = coneProjection k q ↔ p = q := by
  constructor
  · intro heq
    rcases (coneConnected_iff k p q).mp (Quotient.exact heq) with
      hpq | ⟨hz, _⟩
    · exact hpq
    · exact False.elim (hp hz)
  · intro hpq
    rw [hpq]

/-- The equivalence closure's only nontrivial generator identifies
zero-radius points; consequently EVERY related pair has the same
actual radial coordinate. -/
theorem coneConnected_preserves_radius (k : ℕ)
    {p q : ConeCylinder k} (h : ConeConnected k p q) :
    p.2 = q.2 := by
  rcases (coneConnected_iff k p q).mp h with hpq | ⟨hp, hq⟩
  · rw [hpq]
  · exact hp.trans hq.symm

/-- A continuous real radial coordinate descends to the ACTUAL cone
quotient; this is not invented as a label on a finite point set. -/
def coneRadius (k : ℕ) : PerimeterCone k → unitInterval :=
  Quotient.lift (fun p : ConeCylinder k => p.2) (by
    intro p q h
    exact coneConnected_preserves_radius k h)

@[simp] theorem coneRadius_projection (k : ℕ)
    (p : ConeCylinder k) :
    coneRadius k (coneProjection k p) = p.2 := rfl

theorem coneRadius_continuous (k : ℕ) :
    Continuous (coneRadius k) := by
  exact Continuous.quotient_lift
    (show Continuous (fun p : ConeCylinder k => p.2) from continuous_snd)
    (fun _ _ h => coneConnected_preserves_radius k h)

/-- The ACTUAL parent jointly continuous map is constant along each
new cone equivalence class, because parent #959 proves its entire
zero-radius perimeter slice has the SAME radial apex. -/
theorem coneConnected_jointRadialMap_eq (k : ℕ)
    {p q : ConeCylinder k} (h : ConeConnected k p q) :
    perimeterJointRadialMap k p = perimeterJointRadialMap k q := by
  rcases (coneConnected_iff k p q).mp h with heq | ⟨hp, hq⟩
  · rw [heq]
  · rcases p with ⟨x, r⟩
    rcases q with ⟨y, s⟩
    dsimp at hp hq
    subst r
    subst s
    exact (perimeterJointRadialMap_zero k x).trans
      (perimeterJointRadialMap_zero k y).symm

/-- The genuine continuous source-bound cone-to-filling map. It is
a Mathlib Quotient.lift of the ACTUAL previously jointly continuous
perimeter/radius map, not a map invented by filling data. -/
def coneToFilled (k : ℕ) :
    PerimeterCone k → FilledPolygonQuotient k :=
  Quotient.lift (perimeterJointRadialMap k)
    (fun _ _ h => coneConnected_jointRadialMap_eq k h)

@[simp] theorem coneToFilled_projection (k : ℕ)
    (p : ConeCylinder k) :
    coneToFilled k (coneProjection k p) =
      perimeterJointRadialMap k p := rfl

/-- UNCONDITIONAL joint continuity: uses the exact #962 compact/
Hausdorff product-quotient supplier, rather than separate continuity
of fixed-radius slices or an unexplained quotient product axiom. -/
theorem coneToFilled_continuous (k : ℕ) :
    Continuous (coneToFilled k) := by
  exact Continuous.quotient_lift (perimeterJointRadialMap_continuous k)
    (fun _ _ h => coneConnected_jointRadialMap_eq k h)

/-- SURJECTIVE on the ENTIRE genuine filled quotient, since every
radial square source point is an image of the SAME unpaired source
interval at the SAME radius. No dimension/counting shortcut. -/
theorem coneToFilled_surjective (k : ℕ) :
    Function.Surjective (coneToFilled k) := by
  intro z
  refine Quotient.inductionOn z ?_
  rintro ⟨p, r⟩
  refine ⟨coneProjection k (perimeterProjection k p, r), ?_⟩
  exact perimeterJointRadialMap_source k p r

/-- The cone and filled quotient carry the SAME source-preserving
radial coordinate through coneToFilled. In particular the map
cannot collapse different real radial levels. -/
theorem coneToFilled_preserves_radius (k : ℕ)
    (z : PerimeterCone k) :
    radialCoordinate k (coneToFilled k z) = coneRadius k z := by
  refine Quotient.inductionOn z ?_
  rintro ⟨x, r⟩
  exact perimeterJointRadialMap_radius k x r

/-- The selected zero-radius apex of the unpaired perimeter cone. -/
def coneApex (k : ℕ) : PerimeterCone k :=
  coneProjection k
    (perimeterProjection k (originalCornerPoint k (firstHandle k, 0)), 0)

/-- Every original unpaired perimeter point at radial zero is this
SAME cone apex, consuming the actual generating relation. -/
theorem cone_zero_eq_apex (k : ℕ) (x : UnpairedPerimeter k) :
    coneProjection k (x, 0) = coneApex k := by
  apply Quotient.sound
  exact (coneConnected_iff k _ _).mpr
    (Or.inr ⟨rfl, rfl⟩)

/-- The entire cone apex maps to the SOURCE-EXACT filled polygon
apex from #859, not to an arbitrary target zero point. -/
theorem coneToFilled_apex (k : ℕ) :
    coneToFilled k (coneApex k) = apexPoint k := by
  exact perimeterJointRadialMap_zero k _

/-- Actual outer-radius map from the original unpaired perimeter
to its genuine cone. No side pairs are collapsed in this map. -/
def coneBoundary (k : ℕ) :
    UnpairedPerimeter k → PerimeterCone k :=
  fun x => coneProjection k (x, 1)

theorem coneBoundary_continuous (k : ℕ) :
    Continuous (coneBoundary k) := by
  unfold coneBoundary
  exact (coneProjection_continuous k).comp
    (continuous_id.prodMk continuous_const)

/-- The circle boundary remains injective when included into the
unpaired cone, since radius 1 is NOT part of the apex relation. -/
theorem coneBoundary_injective (k : ℕ) :
    Function.Injective (coneBoundary k) := by
  intro x y hxy
  have hsource :
      ((x, (1 : unitInterval)) : ConeCylinder k) = (y, 1) :=
    (coneProjection_eq_iff_of_ne_zero k _ _
      (by norm_num)).mp hxy
  exact congrArg Prod.fst hsource

/-- The cone's outer boundary maps through the already formalized
attaching direction P_k→B_k and the actual continuous boundary map
B_k→Filled. This is a commuting source theorem on ALL points. -/
theorem coneToFilled_boundary (k : ℕ) (x : UnpairedPerimeter k) :
    coneToFilled k (coneBoundary k x) =
      boundaryInclusion k (perimeterAttach k x) := by
  exact perimeterJointRadialMap_one k x

/-- The real standard unit circle is transported into the cone
through the source-specific perimeter circle homeomorphism from
PR #946. The construction is not an S¹→D² characteristic map. -/
def unitCircleConeBoundary (k : ℕ) :
    UnitAddCircle → PerimeterCone k :=
  coneBoundary k ∘ (perimeterUnitCircleHomeomorph k).symm

theorem unitCircleConeBoundary_continuous (k : ℕ) :
    Continuous (unitCircleConeBoundary k) :=
  (coneBoundary_continuous k).comp
    (perimeterUnitCircleHomeomorph k).symm.continuous

/-- Commutativity of the ORIGINAL circle attaching map #951 with the
cone-to-filling map at the outer cone boundary. -/
theorem coneToFilled_unitCircle_boundary (k : ℕ)
    (z : UnitAddCircle) :
    coneToFilled k (unitCircleConeBoundary k z) =
      boundaryInclusion k (unitCircleAttachingMap k z) := by
  exact coneToFilled_boundary k
    ((perimeterUnitCircleHomeomorph k).symm z)

/-- Explicitly visible, strictly SOURCE-MATCHED noninjectivity:
if coneToFilled were injective then the authentic original perimeter
attaching map would be injective, contradicting its real opposite
a/a⁻¹ midpoint witness in issue #868. -/
theorem coneToFilled_not_injective (k : ℕ) :
    ¬ Function.Injective (coneToFilled k) := by
  intro hInjective
  apply perimeterAttach_not_injective k
  intro x y hxy
  apply coneBoundary_injective k
  apply hInjective
  calc
    coneToFilled k (coneBoundary k x) =
        boundaryInclusion k (perimeterAttach k x) :=
      coneToFilled_boundary k x
    _ = boundaryInclusion k (perimeterAttach k y) :=
      congrArg (boundaryInclusion k) hxy
    _ = coneToFilled k (coneBoundary k y) :=
      (coneToFilled_boundary k y).symm

/-- The topological cone is COMPACT, since the genuine perimeter is
compact via #946's finite interval proof, I is compact, and Mathlib
proves compactness of coinduced quotient spaces. -/
theorem perimeterConeCompactSpace (k : ℕ) :
    CompactSpace (PerimeterCone k) := by
  let : CompactSpace (UnpairedPerimeter k) :=
    unpairedPerimeterCompactSpace k
  have : CompactSpace (ConeCylinder k) := by infer_instance
  exact Quotient.compactSpace

/-- Independently the actual filled quotient is compact as a quotient
of finitely many real unit squares. This does NOT imply Hausdorff or
a manifold without a separate source theorem. -/
theorem filledPolygonCompactSpace (k : ℕ) :
    CompactSpace (FilledPolygonQuotient k) := by
  have : CompactSpace (RadialSource k) := by infer_instance
  exact Quotient.compactSpace

/-- Cone apex and a true outer boundary point are provably different:
the genuine cone radius is zero at the apex and one at the boundary. -/
theorem coneApex_ne_boundary (k : ℕ)
    (x : UnpairedPerimeter k) :
    coneApex k ≠ coneBoundary k x := by
  intro h
  have hr := congrArg (coneRadius k) h
  have h01 : (0 : unitInterval) = 1 := by
    exact hr
  exact zero_ne_one h01

/-- Genus two: the source cone-to-filling map is a genuine continuous
surjection but identifies two originally distinct outer side points. -/
theorem genusTwo_coneToFilled_noninjective :
    ¬ Function.Injective (coneToFilled 0) :=
  coneToFilled_not_injective 0

/-- Genus three: the additional handle is preserved in the source
and the same opposite-side obstruction persists. -/
theorem genusThree_coneToFilled_noninjective :
    ¬ Function.Injective (coneToFilled 1) :=
  coneToFilled_not_injective 1
