## 1. What the new topological object actually is

Set \(g=k+2\ge2\), and let \(\mathcal C_k=\mathrm{PolygonCorner}(k)=\mathrm{Handle}(k)\times\mathrm{Fin}(4)\) be the original **finite directed edge positions** from #834. Define a real topological source space

\[
E_k=\mathcal C_k\times[0,1].
\]

The finite corner-index factor is given its discrete topology; the interval factor has the usual subspace topology. Thus \(E_k\) is the genuine disjoint union of **\(4g\) closed intervals**, with the exact previously formalized edge-source labels, not an abstract one-point placeholder or a finite list devoid of topology.

The endpoints of neighboring directed edges must agree. More importantly, each signed edge is paired with its opposite, reversing parameter \(t\mapsto 1-t\). In local handle order \(a,b,a^{-1},b^{-1}\), the source defines \`BoundaryGluingStep k\` by the following **only** primitive identifications:

| Identified points in \(E_k\) | Mathematical meaning |
| --- | --- |
| \(((h,0),t)\sim((h,2),1-t)\) | paired \(a\) and \(a^{-1}\) intervals |
| \(((h,1),t)\sim((h,3),1-t)\) | paired \(b\) and \(b^{-1}\) intervals |
| \(((h,0),1)\sim((h,1),0)\) | first/second edge adjacency |
| \(((h,1),1)\sim((h,2),0)\) | second/third edge adjacency |
| \(((h,2),1)\sim((h,3),0)\) | third/fourth edge adjacency |
| \(((h,3),1)\sim((\mathrm{nextHandle}(h),0),0)\) | fourth/next-handle adjacency, with final cyclic wraparound |

These use the actual continuous interval involution \`unitInterval.symm\`. No interior-point identification other than the two opposite-side pairs is inserted, and the original source IDs and cyclic order are preserved.

The quotient relation is **precisely** the smallest equivalence relation generated by those six families of steps:

\[
\mathcal R_k
=\operatorname{Relation.EqvGen}(\operatorname{BoundaryGluingStep}(k)).
\]

The source defines a Mathlib \`Setoid\` with relation \(\mathcal R_k\), followed by

\[
\boxed{B_k:=E_k/\mathcal R_k}
\tag{T1}
\]

as the actual Mathlib \`Quotient\`. Crucially, this quotient is equipped with **Mathlib's coinduced topological quotient structure**. The new source theorem candidates show that the quotient projection

\[
q_k:E_k\longrightarrow B_k
\]

is continuous and is an \`IsQuotientMap\`. They also prove that each individual directed interval map \(t\mapsto q_k((h,i),t)\) is continuous, and that the opposite \(a\)- and \(b\)-parameterizations agree after reflection.

Unlike the parent #834 construction, \(B_k\) contains the interiors of genuine intervals with their quotient topology. It is therefore a real point-set topological object, not a quotient of just the finite corner ID set.

## 2. The precise finite-to-topological source bridge

The parent #834 relation \`DirectCornerGluing k\` had exactly four generators on **finite corner IDs**:

\[
\begin{aligned}
(h,0)&\sim(h,3),&
(h,1)&\sim(h,2),\\
(h,2)&\sim(h,3),&
(h,1)&\sim(\mathrm{next}(h),0).
\end{aligned}
\]

The new source does **not** add these corner equations to its interval quotient as arbitrary axioms. Instead it derives them from the above true interval identifications and adjacency maps:

- \(a\)-pair at \(t=0\) followed by seam \(2\to3\) yields \((h,0)\sim(h,3)\).
- Seam \(0\to1\), reversed, followed by the \(a\)-pair at \(t=1\) yields \((h,1)\sim(h,2)\).
- Seam \(1\to2\), reversed, followed by the \(b\)-pair at \(t=1\) yields \((h,2)\sim(h,3)\).
- The \(b\)-pair at \(t=0\) followed by the fourth-edge-to-next-handle seam yields \((h,1)\sim(\mathrm{next}(h),0)\).

The proof \`direct_corner_gluing_preserved\` consumes the actual constructors of #834. Induction over **Mathlib's real EqvGen** then produces the full transport

\[
u\sim_{\mathrm{corners}}v
\implies
q_k(u,0)=q_k(v,0).
\tag{T2}
\]

Since #834 has a proof candidate that every two corner IDs are related by its concrete generating relation, the source derives:

\[
\boxed{
\forall u,v\in\mathcal C_k,\quad

\tag{T3}

This is an exact statement in a genuine topological quotient: the **original polygon corners** determine one common vertex *point*. It is strictly more concrete than saying the finite corner equivalence has one class; the continuous interval maps and their endpoint gluings now explain why.

## 3. Noncollapse: this quotient still has interior points

Proving a common vertex is insufficient: the completely collapsed one-point quotient would also satisfy it. The new source therefore supplies a hostile invariant.

Let \(\operatorname{Endpoint}(t)\) mean \(t=0\) or \(t=1\). The true interval reflection preserves endpoint status because it exchanges 0 and 1, while adjacency relations identify only endpoints. The new proof \`step_preserves_endpoint\` checks this for **every** primitive gluing step; \`boundary_connected_preserves_endpoint\` propagates it through the full equivalence closure.

The concrete midpoint \(t=\tfrac12\) is not an endpoint, so no interval midpoint can be equivalent to any original polygon corner endpoint. This proves

\[
\boxed{
\forall c,d\in\mathcal C_k,\quad
q_k(c,\tfrac12)\ne q_k(d,0).
}
\tag{T4}
\]

As a result \(B_k\) is a \`Nontrivial\` topological carrier for **every** \(k\ge0\), not an abstract \`PUnit\` or an indiscrete universal relation pretending to be geometry.

## 4. What this is, and what it is not

In particular, \(B_k\) is **not** the quotient of a closed 2-disk by identifying paired boundary intervals. The interior of the disk has not been introduced. The following are still separate, unproved topological obligations:
