## Exact new mathematics and consumer

1. ColoredSourcePorts.Port.comp requires typed middle fiber matching, SameSource,
   equal boundary colors and equal middle observation. Source metadata and
   every color transition remain in the composite, which preserves the exact
   source observation. Matching recorded strings is not a Git verification.
2. Port.Reversible.comp retains a two-sided inverse if each constituent
   already has an independently proved two-sided inverse. Observation
   preservation alone does not imply an inverse.
3. CMColoredHarmonicTubePorts.lower_lift and lift_lower exactly reconstruct
   (finite signed frame, modular chart). The chart is part of the input:
   dropping it while lowering a generic tube loses geometric information.
4. sourcePosition_move respects actual group multiplication in SL(2,Z).
   sourcePosition_injective requires injectivity of original source indices.
   This moves a geometric upper-half-plane sample, not mu(n) or an AdS5 point.
5. channelAmplitude_partition and sum_channelWave return the complete SIGNED
   packet from all six channels. For signed amplitudes a_i, modes K_i and
   channels c_i:
       F_c(x,z) = sum_{i : c_i=c} a_i K_i(x,z)
       sum_c F_c(x,z) = sum_i a_i K_i(x,z).
   Squaring preserves all mixed terms:
       (sum_c F_c)^2 = sum_c sum_d F_c F_d.
   Replacing that with sum_c F_c^2 would generally be incorrect.
6. channelJet_harmonic uses the existing algebraic finite Fourier second
   jet theorem. The selected benchmark varies in just one of the four
   boundary coordinates; a general 4D differentiated field is not claimed.
7. CMColoredTubePortRoundTrip.fullCycle_is_identity is a concrete and exact
   arithmetic -> harmonic -> arithmetic PortFiber instance. The source is
   (SourceFrame, SL(2,Z) chart), not SourceFrame alone, and it returns the
   entire pair rather than only a source statistic.

## Independent hostile comparisons

- Modular inversion S takes 2i to i/2. It is not a permutation of the
  fixed Gaussian-integer grid. Its action on original indexed images is
  injective, assuming source labels are injective.
- The 2D modular fractional-linear action, 4D conformal inversion and
  arithmetic Möbius function remain distinct mathematical types.
- Distinct channel amplitudes can have nonzero cross terms after squaring.
- A missing physical-bit record is not equivalent to mu(n)=0. The original
  PhysicalMoebiusBitGramReturn.signedReadoutDefect retains both ordered
  pair orientations and the original source-minus-readout difference.
- Finite sampled 4D boundary values cannot uniquely determine arbitrary
  continuum fields by CMFiniteBoundaryReconstructionObstruction.
- An arbitrary signed amplitude vector is not automatically the original
  Möbius causal waveform. The neutral boundary trace returns exactly the
  CHOSEN finite amplitude sum; source identification needs a separate proof.
- A finite sofic graph may admit every trace and lose information in its
  vertex projection. The precise lossless and graph distinction already
  appears in DynamicSoficExactLanguageBoundary.
- The token count, source identity string, Hamming/Hilbert features and
  waveform similarity are retrieval data, not semantic proof certificates.
- A longest-path computation on an acyclic dependency graph is not a
  general longest-simple-path algorithm for a cyclic candidate graph.
  There is no ETH-based optimization theorem or runtime guarantee here.
