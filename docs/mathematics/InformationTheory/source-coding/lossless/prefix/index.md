The study of injective variable-length encodings of a finite source alphabet into finite nonempty words over a finite coding alphabet, with no assigned word a prefix of another distinct assigned word.

**Scope.** The coding alphabet has cardinality D at least two; this local convention excludes empty codewords, including in the singleton-source case. Prefix-free codes support immediate word-boundary detection in a concatenated stream. Unique decodability alone need not provide that property. Expected-length optimality additionally requires a source distribution and an allowed code class.
