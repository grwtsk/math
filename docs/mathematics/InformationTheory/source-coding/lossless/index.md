The study of source representations from which every admissible input can be recovered exactly, including length constraints, decodability and compression efficiency.

**Scope.** For a deterministic single-message code, the encoder is injective on the admitted message set. Unique decoding of concatenated messages is a stronger requirement than single-message injectivity; framing can change the problem. This page reserves lossless for exact reconstruction, distinguishing almost-lossless schemes with a nonzero or asymptotically vanishing error probability.
