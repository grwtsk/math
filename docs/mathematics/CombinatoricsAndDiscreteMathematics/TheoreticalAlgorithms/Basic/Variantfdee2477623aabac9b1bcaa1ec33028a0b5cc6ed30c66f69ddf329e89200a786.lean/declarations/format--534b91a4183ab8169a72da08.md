  -/

  /--
  `nest indent f` increases the current indentation level by `indent` while rendering `f`.

  ```lean example
  open Std Format in
  def fmtList (l : List Format) : Format :=
    let f := joinSep l  ("," ++ Format.line)
    group (nest 1 <| "[" ++ f ++ "]")
  ```

  linebreaks after the commas and indent later lines by 1.
