The study of injective maps between ordered structures for which `a <= b` holds exactly when `f(a) <= f(b)` holds, including existence, obstructions, and order isomorphisms.

**Scope.** Preservation and reflection are separate requirements. An injective monotone map can add comparisons and fail to be an order embedding. Surjective embeddings are order isomorphisms. A relation representation without order axioms requires its own qualification; finiteness and a list address supply neither axioms nor reflection.
