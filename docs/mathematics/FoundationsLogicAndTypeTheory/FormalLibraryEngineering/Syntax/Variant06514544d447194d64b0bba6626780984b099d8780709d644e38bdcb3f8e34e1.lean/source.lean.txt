What is formalized:
Pure finite syntax for Exp-Minus-Log presentations.  The core grammar is
generated by a constant `one`, natural-number variables, and one ordered binary
constructor `node`.

What is certificate-gated:
Any claim that a Presentation expression realizes a mathematical object is
deferred to separate realization certificates.

What is not claimed:
This file does not claim BSD, RH, analytic continuation, or any spectral
correspondence theorem.

Primary mathematical source:
Internal Presentation design notes on the grammar generated by `1`, variables,
and one binary constructor.
-/

namespace Presentation

/-- Core Presentation expression syntax. Natural-number variables keep coding canonical. -/
inductive Expr where
  | one : Expr
  | var : Nat → Expr
  | node : Expr → Expr → Expr
deriving Repr, DecidableEq

namespace Expr

/-- Base constant `e`, represented syntactically as `node(1, 1)`. -/
def e : Expr :=
  node one one

/-- Presentation syntax for a formal logarithm expression. -/
def ln (x : Expr) : Expr :=
  node one (node (node one x) one)

end Expr

end Presentation
