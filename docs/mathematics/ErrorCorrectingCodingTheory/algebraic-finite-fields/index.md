The study of error-detecting and error-correcting codes over finite fields whose constructions, properties or decoding are formulated using algebraic structures and maps.

**Scope.** The field order is a prime power, with the actual field operations specified. Vector spaces, polynomial evaluations and quotient rings supply different constructions; their use is not an assertion that every resulting code is cyclic or meets an optimal bound. Codes over more general rings remain a related but separately scoped setting. A field of four elements is not the ring of integers modulo four.
