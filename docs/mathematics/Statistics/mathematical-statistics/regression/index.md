The mathematical study of models and procedures relating a response to explanatory variables, including estimation and uncertainty for features of the response conditional on those variables.

**Scope.** Conditional means are common targets, but other conditional features and response distributions also occur. Regression does not inherently establish causation, and prediction at new covariate values needs its own assumptions. Model specification, parameter identifiability, fitting criteria and numerical implementation are distinct questions. Linear regression is one selected model family, not the definition of all regression.
