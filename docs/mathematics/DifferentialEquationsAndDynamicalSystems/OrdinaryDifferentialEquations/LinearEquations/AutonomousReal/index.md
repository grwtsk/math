The study of homogeneous constant-coefficient real systems x'=Ax on finite-dimensional vector spaces, viewed both as linear ordinary differential equations and as smooth linear flows.

**Scope.** Fix n>=1 and a real n-by-n matrix A. The evolution x(t)=exp(tA)x(0) is defined for every real t. No diagonalizability, normality, spectral sign or Hamiltonian structure is assumed. Stability criteria must distinguish boundedness, convergence and defective eigenvalues. Adding forcing changes the selected homogeneous problem; finite-dimensional global existence is not automatically inherited by nonlinear vector fields or unbounded operators.
