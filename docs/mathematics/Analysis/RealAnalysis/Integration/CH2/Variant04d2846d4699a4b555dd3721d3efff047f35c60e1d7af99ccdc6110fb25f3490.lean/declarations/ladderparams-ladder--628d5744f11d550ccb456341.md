def LadderParams.ladder (l : LadderParams) : Set ℂ :=
  {z : ℂ | (∃ n, z.re = l.σ n ∧ |z.im| ≤ l.T) ∨ (z.re ≤ 1 ∧ |z.im| = l.T) }

for `n ≥ 1` (excluding the `σ 0 = 1` column, which is part of `∂R`). This is the set on which
