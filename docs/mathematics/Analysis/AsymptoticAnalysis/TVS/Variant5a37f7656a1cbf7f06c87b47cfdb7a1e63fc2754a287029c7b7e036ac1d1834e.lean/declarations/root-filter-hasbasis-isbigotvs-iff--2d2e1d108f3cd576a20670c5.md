protected theorem _root_.Filter.HasBasis.isBigOTVS_iff
    {ιE ιF : Sort*} {pE : ιE → Prop} {pF : ιF → Prop}

      ∀ᶠ x in l, egauge 𝕜 (sE i) (f x) ≤ egauge 𝕜 (sF j) (g x) := by

for each neighborhood `U` of the origin in the codomain of `f`,
