# Compact autocorrelation regularity

On A>=1 the full source/dilation realization and almost-everywhere uniqueness
of admitted weak second derivatives are proved. Arbitrary representatives need
not agree pointwise. For A>0, actual correlation is globally C4 and the literal
finite kernel C2, with compact support and integrable first/second kernel
derivatives. The source is C1 with a globally Lipschitz first derivative, whose
ordinary second derivative agrees with the explicit representative away from
the seams and almost everywhere. The power-four zero extension is not
C-infinity. For every A>0 the actual normalized source is not globally C2:
its first derivative is not differentiable at the right support seam. This is
compatible with the proved C4 correlation; no C5 correlation assertion follows.
