The study of data-dependent procedures that return one value in a specified target space as an estimate of an unknown statistical quantity.

**Scope.** The value may be a vector or function rather than a single real number. Bias, risk, consistency and efficiency refer to a specified model, loss and sampling regime. They are not interchangeable optimality claims. An estimator is the rule before observing data; an estimate is its realized output. A rule that is unbiased need not minimize every loss.
