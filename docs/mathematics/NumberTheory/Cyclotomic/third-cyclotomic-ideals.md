# Ideal norms in the third cyclotomic integer ring

Take the literal field $K=\mathbb Q(\zeta_3)$, represented by
`CyclotomicField 3 ℚ`, and its actual ring of integers
$O=\operatorname{RingOfIntegers}(K)$. The local aliases retain these exact
definitions from the pinned source. Actual instance synthesis supplies the
commutative ring, Dedekind domain, characteristic zero, and finite free
$\mathbb Z$-module structure required by the ideal-norm support theorem.

The actual `IsCyclotomicExtension {3} ℚ K` instance is supplied explicitly
by the pinned cyclotomic-field API, as in the source. Both the field degree over $\mathbb Q$ and the integer-module rank are two.
For every natural $n$, the actual ideal absolute norm satisfies
$N(\langle n:O\rangle)=n^2$. In particular, the ideal generated by two has
absolute norm four in $O$.

## Compact-window support over the actual ring

The [ideal-norm support theorem](../Ideal/compact-norm-support.md) now has an
actual consumer over this $O$. Let $W:\mathbb R\to\mathbb C$ have compact
support, $X>0$, and $F:\operatorname{Ideal}(O)^3\to\mathbb C$. Assume $F$ is zero
when any ideal is zero, and is zero whenever
$W(N(I)N(J)^3N(H)^3/X)=0$. Then `Function.support F` is finite. The result uses
actual ideals and `Ideal.absNorm`, with all ring instances supplied; it does
not assume the desired finite support.

The actual positive consumer uses `schwartzCutoff 1`, whose value at one is
one, and scale four. It cancels zero ideals and otherwise evaluates this
window at the actual norm product divided by four. Its support is finite.
At the triple $(\langle2:O\rangle,1,1)$ the norm product is four, so the value
is one. This is a nonzero term over the actual degree-two integer ring.

In contrast, the actual integer ideal $\langle2:\mathbb Z\rangle$ has norm two.
The unequal values four and two are proved using the two actual norm
functions. The zero-generator branch has norm zero. The sole intended
negative tries to use the proved $O$-norm-four theorem as a proof that the
same $O$ ideal has norm two; the type checker rejects it after the positive
inequality proof.
