    [AddMonoidHomClass F M N] (g' : F) (f : α → α) (g : α → M) (n : ℕ) :
    ⇑g' ∘ birkhoffSum f g n = birkhoffSum f (g' ∘ g) n :=

/-- If a function `φ` is invariant under a function `f` (i.e., `φ ∘ f = φ`), then the Birkhoff sum
