# Zero-independent packing no-go

The s=2 Dirichlet-damped packing is a valid positive arithmetic control and has PNT-free decay. It is not, by itself, an informative zero-facing model.

Suppose a fixed sequence V_n does not depend on a zero s and V_n tends to zero. If one asks for

V_n = lambda_n H(s) + R_n,

with lambda_n tending to L>0 and R_n tending to zero, then taking limits gives

0 = L H(s),

hence H(s)=0.

For the repository quartic witness this immediately gives Re(s)=1/2.

Therefore a theorem producing this fixed comparison for every nontrivial zero would already contain the RH conclusion. The explicit formula cannot be expected to create that information from a zero-independent vanishing sequence.

The corrected architecture keeps:

- canonical prime-power schedule;
- source-faithful coefficients;
- Gram/squared-volume positivity;

but makes the arithmetic point depend on a source/test parameter attached to the zero-facing transform before the Gram is formed.

The required future shape is

zero or test datum
  -> explicit-formula multiplier/transform parameter
  -> parameter-sensitive prime-power points
  -> positive three-point Gram stages
  -> signed-quartic comparison.

This prevents the target information from being inserted only through the residual or the comparison theorem.

The fixed s=2 damped sequence remains useful as a control fixture and asymptotic majorant.
