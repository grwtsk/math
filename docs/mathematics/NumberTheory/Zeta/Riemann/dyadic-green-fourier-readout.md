# Fourier modes are actual admissible source readouts

The Parseval coefficients are now attached back to the repository source action.

For every nonzero integer k, Mathlib gives an explicit antiderivative of the unit-circle Fourier monomial. Subtracting its value at zero produces a C1 function whose values at both 0 and 1 are zero and whose derivative is the Fourier mode.

Package this function and derivative as a ComplexTest.

The existing exact centered integration-by-parts identity then has no endpoint contribution for this test, so

action_X(test_k)
 = - integral residual_X(t) fourier(-k,t)
 = - c_X(k).

Therefore the squared norm of the action equals the squared norm of the Fourier coefficient.

Thus the nonzero Fourier Parseval coordinates are not arbitrary post-processing. They are exact admissible source readouts generated by the unchanged dyadic arithmetic discrepancy.

Together with Parseval, this supplies a growing family of source-faithful positive readout cells that captures the full Green residual energy. The zero Fourier mode is separately killed by the centering identity and can be discharged directly.

The next step is to formalize zero-mode vanishing and then package finite symmetric sets of these admissible Fourier tests as a growing frame whose total squared action converges to greenEnergy, with mass0 and mass1 retained as separate source coordinates.
