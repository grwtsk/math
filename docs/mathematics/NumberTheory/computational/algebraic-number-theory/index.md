The study of algorithms for algebraic-number arithmetic and invariants, with explicit representations of number fields, their orders, ideals and related algebraic structures.

**Scope.** Selected problems include computing rings of integers, units, class groups and Galois information. Inputs, promised hypotheses and conditional versus unconditional guarantees must be stated for each algorithm; one task does not certify all the others. An exact algebraic representation is distinct from a floating-point approximation, and testing an implementation is distinct from proving its mathematical specification.
