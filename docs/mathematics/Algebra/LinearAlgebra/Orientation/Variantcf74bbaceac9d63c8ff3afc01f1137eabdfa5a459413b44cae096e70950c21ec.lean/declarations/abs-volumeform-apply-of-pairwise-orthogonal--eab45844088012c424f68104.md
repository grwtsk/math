    (hv : Pairwise fun i j => ⟪v i, v j⟫ = 0) : |o.volumeForm v| = ∏ i : Fin n, ‖v i‖ := by

  have hdim : finrank ℝ E = Fintype.card (Fin n.succ) := by simpa using _i.out
