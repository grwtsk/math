# Spectrum (commutative ring)

[Objects](index.md) · [Facets](../index.md)

## Definition

For a commutative ring R with identity, its prime ideals form Spec(R); equip this set with the topology whose closed sets consist of prime ideals containing a specified ideal.

## Scope

This record concerns the topological prime spectrum. An affine scheme additionally carries its structure sheaf. Neither is automatically the [bounded-operator spectrum](operator-spectrum.md), and identical labels supply no mathematical equality or taxonomy merge.
