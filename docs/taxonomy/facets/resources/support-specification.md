# Formalization support specification

[Resource kinds](index.md) · [Facets](../index.md)

## Definition

A formal resource specifying formalization support data or interpretation rules,
such as checklists, status vocabularies, dependency policies, bibliography records
and presentation boundaries.

## Scope

A checklist membership theorem does not discharge the listed obligation. A
`checkedByLean` constructor, `Clean` field, report path or acceptance flag does not
constitute a compilation receipt, performed audit, human endorsement or permission.
Concrete list and encoding properties can additionally warrant a mathematical
subject association; these two roles must not be conflated. Generated reports,
mutable queues and execution state belong in Noeaaeue, not in this vocabulary.

The [proposal](../../proposals/new-concepts/semantic-review-resources.md) records
the local warrant and limitations. No semantic parent edge is asserted.
