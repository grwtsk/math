# Differential geometry

[Geometry](../index.md) · [Subjects](../../index.md) · [Taxonomy](../../../index.md)

## Definition

The study of smooth geometric structures using differentiation, including smooth manifolds, tangent constructions, connections and the geometry of maps and submanifolds.

## Scope

Smooth structure is not specified by a topological space alone, and a smooth manifold need not come with a chosen Riemannian metric. Abstract intrinsic geometry and embedded geometry must be distinguished. A coordinate formula must include its chart and regularity assumptions.

## Browse

Selected division criterion: Additional smooth geometric structure. Browse [Riemannian geometry](RiemannianGeometry/index.md).

## Example and boundary

A change of chart changes the components used to describe a tangent vector; this does not turn the vector into a different geometric object.
