# Order theory

[Subjects](../../../index.md) · [Registry](../../../../registry.md)

## Definition

Relations expressing order and their associated structures, including partially ordered sets, lattices and order-preserving maps.

## Scope

A use of comparison in software is not by itself a theorem about ordered structures.
