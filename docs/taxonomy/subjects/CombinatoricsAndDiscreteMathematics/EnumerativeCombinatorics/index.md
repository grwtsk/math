# Enumerative combinatorics

[Combinatorics](../Combinatorics/index.md) · [Subjects](../../index.md) · [Taxonomy](../../../index.md)

## Definition

The study of counting combinatorial objects and determining the sequences, formulas and generating functions that describe those counts.

## Scope

Objects, size parameters, labels, weights and equivalence conventions determine what is counted. Labeled counts need not equal counts up to isomorphism. Bijections, recurrences and generating functions are methods within this subject, not interchangeable names for it. A list of generated objects is not automatically a complete enumeration.

## Browse

Selected division criterion: Counted family or refinement of a counting problem; the pilot selects graph colorings. Browse [Chromatic polynomial theory (finite simple graphs)](../GraphTheory/Coloring/FiniteSimpleVertexColoring/ChromaticPolynomials/index.md).

## Example and boundary

Three distinguishable objects have different arrangement counts from three indistinguishable ones. The convention belongs in the counting question, not in a filename.
