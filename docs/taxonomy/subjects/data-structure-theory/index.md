# Theory of data structures

[Subjects](../index.md) · [Registry](../../registry.md)

## Definition

Mathematical specifications and properties of representations and operations on finite or recursively defined data.

## Scope

Includes lists, arrays, maps and trees as mathematical representations. Runtime performance and implementation qualification require separate evidence.
