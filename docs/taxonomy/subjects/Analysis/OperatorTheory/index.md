# Linear operator theory

[Functional analysis](../FunctionalAnalysis/index.md) · [Analysis](../index.md)

## Definition

The study of linear operators on structured vector spaces, including continuity, domains, adjoints and composition.

## Scope

Bounded operators and appropriately specified unbounded operators belong here. An unbounded operator includes its domain; a formal expression alone is not its complete identity. Nonlinear operator theory is not silently identified with this concept.

Selected child division criterion: aspect of operator behavior. Browse [spectral theory](SpectralTheory/index.md). The proposed semantic parent is [functional analysis](../FunctionalAnalysis/index.md).
