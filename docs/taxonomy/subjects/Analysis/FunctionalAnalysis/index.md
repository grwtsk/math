# Functional analysis

[Analysis](../index.md) · [Subjects](../../index.md)

## Definition

Analysis of topological vector spaces, their linear functionals and operators, including infinite-dimensional phenomena.

## Scope

Finite-dimensional examples remain legitimate. This pilot does not cover every topological-vector-space theory or nonlinear functional-analytic method. A matrix computation is not evidence that every infinite-dimensional extension is valid.

Selected child division criterion: principal analytic structure under study. Browse [linear operator theory](../OperatorTheory/index.md) and [Banach space theory](BanachSpaces/index.md). The proposed semantic parent is [analysis](../index.md); other relationships remain assessable without duplicating this concept.
