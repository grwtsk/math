# Krylov-subspace theory for linear-system solvers

[Iterative solution theory for linear systems](../index.md) · [Subjects](../../../../../index.md) · [Taxonomy](../../../../../../index.md)

## Definition

The study of linear-system approximations built from subspaces generated by repeated action of a system operator on a starting residual, and of the associated projection and recurrence algorithms.

## Scope

For a fixed square matrix A and residual r_0, the basic space is span(r_0,A r_0,...,A^(k-1)r_0). This page selects linear-system solvers, not every eigenvalue or matrix-function use of Krylov spaces. Preconditioned and restarted variants require their own operator and subspace specifications. The spaces alone do not specify a unique solver or its convergence guarantees.

## Browse

Selected division criterion: Algorithm and operator assumptions; the real symmetric positive-definite conjugate-gradient case is selected.

Selected narrower subjects: [Conjugate-gradient theory (real symmetric positive-definite systems)](conjugate-gradient-spd/index.md).

## Example and boundary

A zero starting residual already solves the system. The later vectors in a formal spanning list need not be linearly independent; a fixed list length does not prove that dimension.
