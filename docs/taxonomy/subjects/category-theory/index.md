# Category theory

[Subjects](../index.md) · [Registry](../../registry.md)

## Definition

Objects, morphisms, identities and associative composition, together with structure-preserving functors and natural transformations.

## Scope

Not an alias for all algebra, homological algebra, or type theory. Repository imports and names support candidate retrieval, not subject acceptance.

No semantic parent is asserted in this increment. These canonical draft identities
allow distinct candidate channels without equating their scopes with an existing
broad subject. Directory names, retained labels and imports are observations only.
