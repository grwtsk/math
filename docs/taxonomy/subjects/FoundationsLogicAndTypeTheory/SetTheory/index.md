# Set theory

[Mathematical logic](../MathematicalLogic/index.md) · [Subjects](../../index.md) · [Taxonomy](../../../index.md)

## Definition

The study of sets, membership and the structures and principles governing collections, including infinite collections and axiomatic theories of them.

## Scope

Elementary set constructions, axiomatic set theory and infinite combinatorics are within the subject. A chosen axiom system must be stated for results that depend on it. This record does not identify every foundation with ZFC, admit unrestricted comprehension, or confuse an implementation container with a mathematical set.
