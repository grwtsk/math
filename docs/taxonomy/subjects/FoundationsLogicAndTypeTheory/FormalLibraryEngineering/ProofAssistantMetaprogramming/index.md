# Proof-assistant metaprogramming

[Subjects](../../../index.md) · [Registry](../../../../registry.md)

## Definition

Construction and analysis of programs that inspect or construct formal syntax, elaboration tasks and proof-assistant computations.

## Scope

A tactic or elaborator implementation is not automatically a theorem about its correctness. Proof production and kernel acceptance remain separate.

No semantic parent is asserted in this increment. These canonical draft identities
allow distinct candidate channels without equating their scopes with an existing
broad subject. Directory names, retained labels and imports are observations only.
