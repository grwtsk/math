# Type theory

[Subjects](../index.md) · [Registry](../../registry.md)

## Definition

Formal systems of types, terms and typing judgments, with their rules of formation, introduction, elimination and equality.

## Scope

Not every Lean declaration is a result about type theory. Dependent types used as a representation are recorded separately from subject claims.

No semantic parent is asserted in this increment. These canonical draft identities
allow distinct candidate channels without equating their scopes with an existing
broad subject. Directory names, retained labels and imports are observations only.
