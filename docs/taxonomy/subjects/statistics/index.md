# Statistics

[Subjects](../index.md) · [Taxonomy](../../index.md)

## Definition

The discipline concerned with designing the collection of data, describing variation, and drawing and assessing conclusions from data in the presence of uncertainty.

## Scope

This subject includes mathematical theory and empirical practice. It is not the same record kind as a statistic, a dataset, a software package or a numerical summary. Probability supplies mathematical models, but a relationship to probability does not make every statistical question a probability theorem. Data quality, measurement, sampling and interpretation remain part of the broader subject even when a formal model is used.

## Browse

Selected division criterion: Statistical research by theoretical or applied focus; only the mathematical-theory branch is populated in this batch.

Selected narrower subjects: [Mathematical statistics](mathematical-statistics/index.md).

## Example and boundary

A study may ask what should be measured before asking how an estimate should be calculated. A correct calculation cannot repair an unspecified target population or a systematically misleading measurement.
