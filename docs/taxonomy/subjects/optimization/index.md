# Mathematical optimization

[Subjects](../index.md) · [Taxonomy](../../index.md)

## Definition

The study of selecting feasible mathematical objects to minimize or maximize a specified objective, including existence, structure, characterization and computation of optima.

## Scope

Continuous, discrete, constrained and unconstrained problems belong to the wider subject. Feasibility, attainment, uniqueness, local optimality and global optimality are different questions. The field is not limited to efficient algorithms or to convex problems, and an objective in a model is not an operational authorization or a guarantee that the model represents an application.

## Browse

Selected division criterion: Problem geometry; this batch selects a convex branch without asserting that every other class forms one complementary discipline.

Selected narrower subjects: [Convex optimization](convex/index.md).

## Example and boundary

The function exp(x) on the real line has infimum zero but no minimizing real point. An optimal value and an optimizer must therefore be distinguished.
