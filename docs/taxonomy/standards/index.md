# Standards, literature and rights register

[Taxonomy](../index.md) · [Reference-only decision](../decisions/index.md#d02-reference-only-external-sources)

Register revision 0.2; retrieval/inspection date for the sources below (new L4/L5 and MSC/CC references rechecked for 0.2): **2026-10-19**. Source keys are local bibliographic keys, not invented authority identifiers. Every external original-byte checksum is **UNAVAILABLE**: this review used retrieved web text and selected rendered PDF pages, not a retained, hash-verified original-byte package. No checksum or immutable snapshot is fabricated. The [MSC source/access and rights profile](msc2020/index.md) records the original-byte acquisition gap separately from reference-only local authoring. Mutable web locations require later byte capture and release reconciliation where legally permitted.

The permitted pilot mode is citation/reference plus locally authored explanation. No source-owned classification dataset, complete standard or book is redistributed. Local prose follows the repository's MIT convention; this does not relicense cited sources or determine whether a future adaptation is permitted. Unresolved access/reuse questions block the affected import/export operation, not inclusion of the mathematical field in the declared scope.
