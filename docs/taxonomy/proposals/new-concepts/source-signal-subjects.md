# Source-signal subject draft

## Problem and affected identities

The path-only queue policy leaves hash-named maintained source occurrences
unrouted and lacks identities for five recurrent subject families. Every regular
Lean file under GRWTSK remains maintained, regardless of storage prefix.
The five identities above add navigation without moving or renaming any source.

## Evidence and limitations

The local source warrant records the inspected repository revision and scope.
Noeaaeue observes imports, namespaces and retained organization labels, excluding
comments and string contents from code signals. Each candidate has exact source
bindings and the triggering rules. Retained source provenance and exact-original
hash links are evidence for retrieval, not automatically accepted taxonomy edges.
The retained PMD snapshot is not silently equated with this UUID scheme.

## Alternatives and recommendation

Do not merge category theory into algebra, type theory into all logic, or software
metaprogramming into proof acceptance. Add separate proposed identities. Rules may
multicast to more than one channel. Preserve unmatched or ambiguous cases for
review rather than assign an invented catch-all mathematical subject.

## Before, after and compatibility

Before: the pilot lacks these five concepts and the queue uses seven path-only
channels. After: five draft concepts, no new semantic parent edges, and Noeaaeue
source-signal routing with persistent observations. Prior IDs, source namespaces,
editorial statuses and proof states remain unchanged. Routing changes do not
invalidate or manufacture mathematical replay evidence.

## Acceptance criteria and retained rationale

Check canonical ID uniqueness, source bindings, lossless task accounting and
rule determinism. Independently review each definition, source-to-subject
association and any proposed semantic parentage. External terminology and
literature warrants remain incomplete; no production taxonomy release is claimed.
Counts and per-source generated ledgers belong to Noeaaeue, not editable prose.
