# Retained policy inputs

The two Markdown files in this directory are exact byte copies of the
user-supplied migration and rigor/reconstruction addenda received on
2026-10-13. They are retained inputs to policy version
`rigor-and-reconstruction-addendum-1.0.0`.

They are instructions and authorization context, not repository-conformance
evidence, mathematical evidence, or verification receipts. Their SHA-256
identities and paths are checked by the rule-registry validator. The human
request to implement them remains the authorization; retaining these bytes
does not allow the registry to authorize itself or weaken a prior policy.
