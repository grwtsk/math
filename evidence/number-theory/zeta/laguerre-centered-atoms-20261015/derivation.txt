1. Unchanged source and exact centering on the integer labels
-------------------------------------------------------------
For real x>=1 retain
 Delta(x)=sum_(2<=n<=x) Lambda(n)-x+1, Delta(1)=0,
 u_k^(X)=integral_0^log(X) Delta(exp(t)) exp(-3t/2) L_k(2t) dt,
 D_N^(X)=sum_(k<N) |u_k^(X)|^2.
Here Lambda(p^j)=log(p), including every prime power, and Lambda=0 otherwise.
The prior repository note and pending tested package define these very objects;
the finite head is not the full infinite prime-label integral.

Set d_n=Lambda(n)-1 for EVERY integer n>=2, not only prime powers. Put
 C(x)=sum_(2<=n<=x) d_n and delta(x)=floor(x)-x. Then EXACTLY
 Delta(x)=C(x)+delta(x).
This includes noninteger x, all touching atoms, and the initial interval [1,2).
At an integer x the mesh error is zero but the cumulative step is not removed.
Negative labels and the subtraction of the deterministic density are retained.

Fix finite real X>=1, L=log X, and M=floor X. For 2<=n<=M define
 A_k(n;X)=integral_log(n)^L exp(-3t/2) L_k(2t) dt,
 z_k^(X)=sum_(n=2)^M d_n A_k(n;X),
 epsilon_k^(X)=integral_0^L delta(exp(t)) exp(-3t/2) L_k(2t) dt.
Then u_k^(X)=z_k^(X)+epsilon_k^(X). At integer X the n=X feature is
exactly zero. Its label remains in the inventory and in both endpoint terms.
This is a linear change of bookkeeping, not a change of the source.

2. A uniform mesh bound and the actual projected atom Gram
---------------------------------------------------------
The real functions phi_k(t)=sqrt(2) exp(-t)L_k(2t) are orthonormal in
L2(0,infinity;dt). A direct proof uses Rodrigues' formula
 L_k(x)=exp(x)/k! * (d/dx)^k (exp(-x)x^k).
Integrate by parts k times against lower-degree polynomials with weight
exp(-x); all boundaries vanish. The degree-k leading coefficient gives norm
one. Substitution x=2t proves the stated normalization. This is classical
Laguerre orthogonality, not a theorem about prime cancellation.

Let h_(n,X)(t)=2^(-1/2) exp(-t/2) 1_[log(n),L](t). Its phi_k coefficient
is precisely A_k(n;X). Let P_N be the orthogonal projection onto k<N and set
 K_(N,X)(m,n)=sum_(k<N) A_k(m;X) A_k(n;X).
The full FUNCTION-SPACE Gram is explicit:
 G_X(m,n)=<h_(m,X),h_(n,X)>=(1/max(m,n)-1/X)/2.
It follows as an operator inequality on this finite label space that
 0 <= K_(N,X) <= G_X.                                      (2.1)
Indeed each quadratic difference is ||(I-P_N)sum v_n h_(n,X)||^2.
No completeness assertion or interchange of an infinite label sum is needed.
In particular K_(N,X)(n,n) <= (1/n-1/X)/2.
Applying (2.1) to the whole source would return the coarse Bessel bound and
can lose the cancellation of interest. We use it only on the diagonal below.

The mesh coefficients are those of 2^(-1/2) exp(-t/2)delta(exp(t))1_[0,L].
Bessel and |delta(x)|<=1 give, uniformly in N and X,
 sum_(k<N) |epsilon_k^(X)|^2
 <= (1/2) integral_1^X |delta(x)|^2 x^(-2) dx <= 1/2.        (2.2)
Taking increasing N retains the same bound for the full coefficient series.
This mesh component can be kept exactly or returned at norm cost 1/sqrt(2).
It is not the gamma component or the previous centered Mobius-cell residual.

3. The complete diagonal costs only quadratically in log X
-----------------------------------------------------------
Define the actual diagonal and ORDERED cross term
 Q_(N,X)=sum_(n=2)^M d_n^2 K_(N,X)(n,n),
 C_(N,X)=sum_(m,n=2)^M, m!=n d_m d_n K_(N,X)(m,n).
Then ||z_(<N)^(X)||^2=Q_(N,X)+C_(N,X), exactly, and Q>=0.
Every order of a mixed pair is retained. C can have either sign.

THEOREM. For every finite N>=1 and real X>=1, with L=log X,
 0 <= Q_(N,X) <= L^2+L/2.                                  (3.1)
Proof. The case M=1 is empty. Otherwise (2.1) and Lambda>=0 imply
 Q <= (1/2)sum_(2<=n<=M) (Lambda(n)-1)^2/n
   <= (1/2)[L sum_(2<=n<=M) Lambda(n)/n + sum_(2<=n<=M)1/n].
Here Lambda(n)^2<=L Lambda(n), and the negative -2Lambda(n) in the diagonal
square was bounded from above, not silently changed in the source.
Unique prime factorization gives the exact finite identity
 sum_(n=2)^M Lambda(n) floor(M/n)=log(M!).
Since floor(M/n)>=M/(2n), sum Lambda(n)/n <=2log(M!)/M<=2log M.
Also sum_(n=2)^M 1/n<=log M. Substituting log M<=L proves (3.1).
No prime number theorem, 7/8 theorem, RH, or zero-density estimate is used.

At the prior tail schedule X_N=2^(11N), log X_N<8N (11 log 2<8), hence
 Q_(N,X_N) <= 64 N^2+4 N, for EVERY N>=1.                    (3.2)
This is an actual universal diagonal estimate, not extrapolated finite data.
The code checks the logarithm comparison and finite identities; the universal
Bessel/integration argument remains a written proof, not Lean admission.

4. Exact energy accounting and the remaining arithmetic inequality
-------------------------------------------------------------------
Keep the mesh interaction in
 D_N^(X)=Q_(N,X)+C_(N,X)+2 Re<z,epsilon>+||epsilon||^2.       (4.1)
Using only (2.2) and the triangle inequality,
 D_N^(X) <=2[Q_(N,X)+C_(N,X)]+1,
 C_(N,X) <=2 D_N^(X)+1,          C_(N,X)>=-Q_(N,X).          (4.2)
The last inequality follows from the COMPLETE Gram square, not from positive
individual mixed terms. No new upper cross bound has been deduced from it.

Therefore at X_N=2^(11N), subexponential upper growth of max(0,C_(N,X_N))
is equivalent to subexponential D_N^(X_N). Polynomial upper growth of C is
sufficient, and lower growth is already controlled by the quadratic diagonal.
The prior package proves
 ||u_(<N)-u_(<N)^(X_N)||^2 <= E_N^2,
 E_N^2=N(91N/45+910/891)^2(36/49)^N ->0.
Combining its tail with (4.2) yields the explicit inequality
 D_N <=256N^2+16N+4 C_(N,X_N)+2+2E_N^2.                     (4.3)
Thus the existing source-specific return consumes a genuine subexponential
UPPER bound on C_(N,X_N). That upper bound is the OPEN arithmetic obligation.
It is not supplied by (3.2), by positivity, or by finite observed cancellation.

5. The exact finite Dirichlet-polynomial interface
--------------------------------------------------
Let s(w)=(3+w)/(2(1-w)), |w|<1, and
 D_X(s)=sum_(n=2)^M d_n n^(-s), B_X=sum_(n=2)^M d_n.
The ordinary Laguerre generating function gives
 sum_(k>=0) z_k^(X)w^k
   =2/(3+w) [D_X(s(w))-B_X X^(-s(w))].                     (5.1)
For a single atom the bracket is n^(-s)-X^(-s), including its touching value.
One proves (5.1) by integrating the generating function over each bounded
interval [log n,log X]. On compact disks |w|<1 the integration is dominated;
the finite label sum introduces no interchange difficulty. Since
s(w)(1-w)=(3+w)/2, the apparent 1/s prefactor is exactly as displayed.

Equivalently A_k(n;X)=n^(-3/2)T_k(log n)-X^(-3/2)T_k(log X), where
 T_k(t)=(2/3)sum_(j=0)^k (-1/3)^(k-j) q_j(2t).
This polynomial equals the exact exponential antiderivative used by the
producer. It avoids any unproved approximation of Laguerre features by phases.
The finite source has become a LITERAL centered Dirichlet polynomial with a
common endpoint term, followed by a fixed stable prefactor and coefficient
projection. Its prime powers, non-prime -1 labels, and B_X remain explicit.

The boundary parametrization is w=(i*tau-1)/(i*tau+1), s=1/2+i*tau.
Consequently one can try Guth--Maynard or related dispersion estimates on the
finite polynomials in (5.1), rather than identify a Hankel matrix with their
phase matrix by name. The theorem's 1-separated observation set, finite time
window, coefficient supremum, dyadic length, all edges of the partition, and
reconstruction to the projected first N coefficients must be proved. A dyadic
block can be normalized using |d_n|<=1+log X, but its full scalar normalization
must be restored. Each block's endpoint coefficient is its OWN sum of d_n;
these sum exactly to B_X. Do not fit new centers or remove the common endpoint.
No such quantitative large-value-to-C comparison is proved in this update.

6. Negative controls and finite scope
-------------------------------------
Already two identical features with labels 1,-1 have diagonal 2, cross -2,
and total zero. M identical features with labels +1 have diagonal M and cross
M(M-1). Positive Gram structure alone cannot provide the required upper bound.
A source-scale control is Delta_model(x)=x-1, NOT the arithmetic discrepancy.
Its exact moments are
 u_k^model=2(-3)^k-(2/3)(-1/3)^k.
They grow exponentially. Replacing the integer labels by d_n=1 changes this
model by the bounded floor correction. Its diagonal still obeys
Q<=sum_(2<=n<=X)1/(2n)<=log(X)/2; it is the cross term that carries the growth.
The prior elementary tail proof also applies to this model. The control rules
out a generic inference from diagonal growth or homogeneous dissipation to
small forcing. It does not constitute a counterexample to RH.

The new finite evaluator uses the actual labels for X=256,1024 and N=8,
separately at 192 and 256 working bits. The displayed output grid is 160 bits.
It checks every factorization, every atom's Bessel diagonal allowance, all
fractional cells, and consistency with the prior complete finite-head evaluator.
The cross term is computed as the complete squared sum minus its diagonal;
this is an exact finite identity, not pairwise absolute-value majorization.
The common primitives make the alternate assembly a consistency check, not
independent verification of the analytic special-function theory.
